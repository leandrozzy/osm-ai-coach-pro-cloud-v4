🔔 OSM AI Coach · Push

Configuração isolada para não mexer no app principal. Depois de ativado, o navegador fica registrado para receber push mesmo com o OSM Coach fechado.

1. Firebase Web Config

No Firebase: Configurações do projeto → Geral → Seus apps → OSM Coach Web → Configuração do SDK. Cole o bloco firebaseConfig inteiro ou somente o objeto {...}.

2. Ativar neste Android

Ainda não configurado.

3. Testar

No teste de 15 s, toque no botão e feche a aba imediatamente. O servidor espera 15 segundos antes de enviar.

Próxima etapa

Para o botão de teste e os alertas automáticos funcionarem, o Vercel precisa da variável secreta FIREBASE_SERVICE_ACCOUNT_JSON. O arquivo deste ZIP já deixa a API pronta; falta apenas cadastrar essa credencial no Vercel.
